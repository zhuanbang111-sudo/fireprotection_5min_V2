# 消防站点 5 分钟等时圈分析工具 V2 (FireIsochrone Pro V2)

这是一个基于 **React + Node.js (Express)** 构建的高级全栈 Web 应用，专门用于消防站点的精细化可达性分析。本工具 V2 版本通过集成高德地图实时路况引擎、复杂的消防特勤仿真算法以及**模型自动标定功能**，为城市消防实战提供科学决策。

## 🚀 核心仿真逻辑 (Analysis Engine V2)

本工具的后端分析模型（`server.ts`）内置了深度优化的消防出警仿真逻辑，模拟真实消防驾驶行为：

### 1. 高效需求锚点探测 (Smart Anchor Scanning)
- **十五页深度扫描**：对中心点周边执行 15 页深度探测，获取约 750 个真实 POI（兴趣点），构建全量覆盖的需求样本库。
- **几何极速补盲**：通过 24 个方向的数学锚点自动撑开边界，不再依赖额外 API 搜索，极大提升分析速度，并防止在郊区或路网稀疏区发生图形塌陷。
- **全量路径规划**：对所有获取到的唯一锚点发起实时的全量路径规划，不再限制点数，保障分析结果的颗粒度与完整性。

### 2. 特勤通行特权仿真 (Emergency Privilege Simulation)
- **极速掉头修正**：识别导航中的“掉头”动作，将其阻滞耗时强行压缩至 **10%**，模拟消防车跨越分界线或特权转向的能力。
- **逆行/绕行优化**：针对起步阶段的路径，通过 **3 折耗时转换**（70% 提速）模拟消防车直接**逆行、翻越护栏或使用特种通道**进入对面车道的实战场景，有效规避了普通导航 API 强制绕行至最近合法路口的局限性。
- **空心化消除**：前端算法优化了等时圈生成的拓扑结构，自动剔除内部“闭合孔腔”，将覆盖范围实心化展示，使结果更符合指挥官的视觉直觉。

### 3. “最后 100 米”地块修正 (Plot Offset Correction)
- **地块内仿真**：常规导航仅止于路边，本工具计算路边点与地块重心（POI 坐标）的残余间隙。
- **速度自定义**：支持用户在界面调节进入地块后的行驶速度（0-15 m/s），真实还原从单位大门到具体起火部位的行驶过程。

### 4. 模型自动标定 (Automatic Calibration)
- **实测数据驱动**：内置标定模块，用户可上传包含“实测出警耗时”的历史数据样本。
- **网格搜索优化**：系统通过穷举拟合，自动寻找最匹配当地交通和消防特性的“特权系数”与“地块速度”，实现从经验推断到数据建模的跨越。

### 5. 全球坐标兼容系统
- **原生 WGS84 支持**：默认支持 WGS-84 标准 GPS 坐标，同时兼容 GCJ-02 与 BD-09。数据入库自动纠编，成果导出零漂移对齐。

### 6. 安全登录与访问控制 (Authentication)
- **D1 身份验证**：支持基于 Cloudflare D1 数据库和邮箱账号的生产级安全身份验证，保护敏感消防规划数据。
- **权限隔离**：内置登录页面，确保只有授权用户可进入仿真分析系统。

## ✨ 功能特性

- **可视化地图预览**：支持 **天地图矢量/影像**、OpenStreetMap 多底图切换。
- **时空足迹渲染**：基于生成的万级轨迹点对云，通过动态网格插值法生成高精度的等时圈。
- **数据批量处理**：支持 Excel/CSV 站点批量上传，支持多 API Key 自动轮换以规避频率限制。
- **多格式导出**：
  - **Excel**：详细的覆盖面积、API 消耗、测算时刻报表。
  - **SHP (WGS84)**：原生 GIS 空间数据格式，方便导入专业规划系统。

## 🛠 技术栈

- **Frontend**: React 18, Tailwind CSS, Leaflet, Lucide React, Motion (动画增强)
- **Backend**: Node.js (Express), Axios (三方请求同步), Dotenv (环境管理)
- **Analysis**: @turf/turf (地理空间拓扑运算), XLSX (电子表格处理)

## 📖 使用指南

1. **秘钥配置**：在侧边栏输入高德 API Key。支持填写多个秘钥（英文逗号分隔）以实现自动负载均衡。
2. **站点加载**：上传包含 `station_name`, `lng`, `lat` 列的 Excel/CSV 文件。
3. **仿真推演**：
   - **时间要求**：设定目标到达时长（如 5 分钟）。
   - **进入速度**：设定车辆通过大门后的地块内速度，模拟小区通达度。
   - **特权系数**：系数越小，代表消防车对社会交通流的超越能力越强。
4. **模型标定**：
   - 切换至“标定”面板，上传含有实测耗时的 Excel 数据包（字段需包含经纬度及 actual_time）。
   - 点击“执行标定”获取推荐参数，并点击“应用”按钮将其同步至分析引擎。
5. **成果获取**：点击“开始分析”，完成后在地图查看形状，或在“统计报表”页面下载数据。

## 📂 项目结构

- `/server.ts`: 后端引擎，包含所有坐标转换、API 聚合及仿真数学模型（带保姆级中文注释）。
- `/src/App.tsx`: 前端主界面，处理地图交互、参数控制及等时圈生成。
- `/src/index.css`: 全局样式，包含基于 Tailwind 的视觉主题定义。

## ⚠️ 注意事项

- 请确保高德 API 秘钥已开启“Web服务”权限。
- 分析过程涉及大量路网计算，请关注当日 API 配额剩余情况。
- **导出 SHP 文件**：默认为 WGS-84 地球标准坐标系。

## 🌐 部署与分享 (Cloudflare / Workers)
本应用已完全适配并全面调优 Cloudflare Workers + Pages/Assets 全栈边缘侧计算架构。

### 1. 构建与边缘端兼容性保障 (Edge Computation Compatibility)
- **自定义 Assert 垫片 (Assert Shim)**：由于 GIS 领域的 `shp-write` 依赖于 Node.js 内置的 `assert` 断言模块，而在 Cloudflare Workers 生态下默认无原生运行时断言，我们特别在打包流程中引入了 `/src/assert-shim.js` 零依赖断言垫片。
- **Esbuild 编译优化 (esbuild Alias Mapping)**：在 `package.json` 的 `build` 脚本中，通过配置 `--alias:assert=./src/assert-shim.js --alias:node:assert=./src/assert-shim.js`，无缝拦截了依赖调用，使其符合 Cloudflare Workers 无遗留打包和 100% 成功部署的标准。

### 2. 部署操作指南
1. **环境变量配置**：
   - 确保 `wrangler.json` 中配置了正确的入口指向 `"main": "dist/worker.js"`。
   - 部署完成后在 Cloudflare 仪表盘 **Wrangler / Workers > Settings > Variables** 中，可以填入您的定制化 `AMAP_KEYS` 与生产秘钥。
2. **快速发布**：
   - 运行项目构建：`npm run build`。该命令将同步执行 Vite 前端静态打包与 Worker 后端极速 esbuild 边缘环境多重编译，并生成 `dist` 目录。
   - 执行边缘发布：使用 `npx wrangler deploy` 便可瞬间上云部署，秒级生效。

### 3. 排障与重要提示
- **405 错误排查**：如果请求后端出现 405，说明 `wrangler.json` 规则未正确跟随上传，Cloudflare Pages 将页面误读为纯静态资源站。请重新运行全流程部署。
- **按键轮换与隔离**：用户可在前端界面、后端环境变量分别注入高德 API Key（系统不会明文公开或落地持久化用户自定义的临时私钥）。
