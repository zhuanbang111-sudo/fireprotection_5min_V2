# 消防站点 5 分钟等时圈分析工具

这是一个基于 **React + Node.js (Express)** 构建的全栈 Web 应用，专门用于消防站点的可达性分析。它利用高德地图 API 获取实时路况和路径规划数据，计算并可视化消防站在规定时间（如 5 分钟）内的等时圈覆盖范围。

## 核心功能

- **多源坐标支持**：支持 GCJ-02 (火星坐标) 和 BD-09 (百度坐标) 的输入，并自动转换为 WGS-84 进行空间计算。
- **等时圈分析**：
  - 自动搜索周边 POI 作为路径规划锚点。
  - 模拟消防车特权（如掉头时间修正）。
  - 基于路径规划数据生成平滑的等时圈多边形。
- **交互式地图**：使用 Leaflet 集成 OpenStreetMap，实时展示站点位置和分析生成的等时圈。
- **数据管理**：
  - 支持 Excel/CSV 批量上传站点数据。
  - 支持分析结果导出为 Excel 报表。
  - 支持分析结果导出为 GeoJSON 空间数据。
- **实时日志**：展示分析过程中的每一步操作，方便排查问题。

## 技术栈

- **前端**：React 18, Tailwind CSS, Leaflet, Lucide React, Motion
- **后端**：Node.js, Express, Vite (作为开发中间件)
- **空间计算**：@turf/turf (地理空间分析库)
- **数据处理**：xlsx (Excel 解析与生成), axios (API 请求)

## 快速开始

### 1. 环境准备
确保您的环境中已安装 Node.js (建议 v18+)。

### 2. 获取高德 API Key
您需要前往 [高德开放平台](https://lbs.amap.com/) 申请 **Web 服务** 类型的 API Key。

### 3. 安装依赖
```bash
npm install
```

### 4. 运行应用
```bash
npm run dev
```
应用将运行在 `http://localhost:3000`。

## 使用指南

1. **配置 API Key**：在侧边栏的“高德 API Keys”文本框中输入您的 Key。如果分析量大，可以输入多个 Key（用逗号分隔）以提高并发能力。
2. **上传数据**：准备一个包含 `station_name`, `lng`, `lat` 三列的 Excel 或 CSV 文件，点击上传区域进行加载。
3. **参数调整**：
   - **坐标系**：根据您原始数据的坐标系选择 GCJ-02 或 BD-09。
   - **到场时间**：设置目标分析时间（如 5 分钟）。
   - **特权系数**：模拟消防车在拥堵路段的通行能力（越小代表通行能力越强）。
4. **开始分析**：点击右上角的“开始分析”按钮。
5. **查看结果**：
   - **地图预览**：在地图上查看生成的红色等时圈。
   - **统计报表**：查看每个站点的覆盖面积、API 消耗等详细数据。
6. **导出数据**：在“统计报表”页面点击导出按钮，获取分析成果。

## 注意事项

- **API 额度**：本工具会为每个站点发起数十次路径规划请求，请确保您的高德 API 额度充足。
- **性能**：等时圈的生成是在浏览器端通过 Turf.js 计算的，站点数量过多或网格密度过大可能会导致短暂卡顿。
- **坐标偏差**：地图底图使用 OSM (WGS-84)，如果您的输入坐标系选择错误，会导致站点位置偏移。
